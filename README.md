# Linux File Permissions

## Project Overview
This project demonstrates basic Linux file and directory permission management using terminal commands.

## Objectives
- Understand Linux file permissions.
- Inspect files and directories using `ls -la`.
- Navigate directories using `cd`.
- Modify permissions using `chmod`.
- Understand owner, group, and other-user permissions.

## Commands Practiced
```bash
pwd
cd projects
ls -la
chmod g-w project_r.txt
chmod g-w project_t.txt
chmod u-w,g-w .project_x.txt
cd drafts
chmod g-x .
```
